# UIC CS 402 Fall 2026

## Project 3: Trees
In this project, you will have practice with trees, one of the most prevalent and important data structures you will ever encounter.
The implementations in this project will encourage you to think about and beyond things we have done in class with trees.
I encourage you to start the project early and ask plenty of questions.

**Please carefully read the algorithm descriptions in `Firstname_Lastname_project3.cpp`. You will need to implement the specified algorithms.**
The project includes

- `Firstname_Lastname_project3.cpp`
    - Your main file where you will implement most of your source code. It also contains the algorithm descriptions you will need to implement, so please read it carefully.
- `Firstname_Lastname_project3.h`
    - Header file with various function signatures. You can add things to the header/`.cpp` file as you need, **but you may not modify function signatures**.

This project is distributed through GitHub and you will write your code using git for version control. My advice to you is to commit early and commit often to your repository to accurately track your progress when writing your project solutions.

### Grading
The project is worth 75 points for all students.

#### Autograder
I will be using an autograder to help speed the process of testing your code. The autograder will test your functions against various test cases that I will write. 
The autograder is included and includes some test cases you can run against your code.
Note that the given test cases do not include all possible tests I will use to grade your project.

> [!NOTE]
> Upon the initial release of this project, there will only be test files for 2 of the functions. Test files for the remaining functions will be included at a later time. I will announce when these tests are available.

#### Manual Inspection
Part of your grade will also come from manual inspection of your code. This is because the auto grader cannot check if you are implementing the correct algorithms, it can only check that you pass some tests. To help make this process smooth and easy, please be sure to write legible and clear code.
